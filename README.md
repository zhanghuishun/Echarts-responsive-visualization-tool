# ECharts 响应式图表参数调节工具

面向 **ECharts 柱状图** 的本地工具：通过侧栏调节图表参数（类目数、组数、柱宽策略、网格等），并调节**模拟画布宽度**，观察不同视口下的响应式表现；支持预设与导出。

技术栈：**Vue 3**、**TypeScript**、**Vite**、**ECharts**。

## 本地运行

```bash
npm install
npm run dev
```

构建：`npm run build`，预览：`npm run preview`。
